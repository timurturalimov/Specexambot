# ПДД РК — Telegram-бот

Тесты в формате ЦОН (экзамен 40 вопросов + тренировка 10), но цель — **понимание правил и безопасности движения**, а не зубрёжка. После каждого ответа бот объясняет, *почему* правило устроено именно так.

## Запуск (Vercel + webhook, бесплатно, как с «Белкой»)

1. Залить папку в GitHub-репозиторий.
2. В @BotFather создать нового бота → получить токен.
3. Vercel → Import репозитория → Environment Variables:
   - `BOT_TOKEN` — токен бота
   - `WEBHOOK_SECRET` — любая случайная строка (латиница/цифры)
   - `SERVE_UNVERIFIED` — `true` на время теста, `false` для публичного запуска (покажет только проверенные вопросы)
4. Подключить webhook (открыть в браузере, подставив свои значения):
   `https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://<проект>.vercel.app/api/webhook&secret_token=<WEBHOOK_SECRET>`
5. Написать боту `/start`.

Команды: `/start`, `/exam`, `/practice`.

## Как это устроено

- Без базы данных. Состояние теста (seed, номер вопроса, маска ошибок) хранится в `callback_data` кнопок. Вопросы и порядок вариантов выбираются детерминированно по seed.
- `data/questions.js` — банк вопросов. У каждого: тема, объяснение `why`, пункт `ref`, флаг `verified`, период действия `from`/`until`.
- Вопросы с `from`/`until` переключаются по дате (Алматы, UTC+5): так бот сам подхватывает изменения ПДД.

## Проверка

```
npm run validate   # схема банка вопросов, статистика по темам
npm test           # логика теста, даты, лимит callback_data
```

## ⚠️ Перед публичным запуском

1. **Сверить вопросы с официальным текстом ПДД** (приказ МВД РК № 534 от 30.06.2023 в актуальной редакции, adilet.zan.kz). Сейчас `verified: true` у 14 из 32; остальные — черновик. Сверил → заполнил `ref` → поставил `verified: true`.
2. **Изменения с 20.11.2026** (грузовики/автобусы до 90 км/ч там, где знак 3.24 разрешает; электросамокаты; велосипеды с двигателем приравнены к мопедам) заведены вопросами с `from: '2026-11-20'`. Источник — новостные статьи, нужно сверить с опубликованным текстом поправок (приказ МВД № 305 от 27.04.2026 и последующие).
3. Проходной балл ЦОН в бот не зашит — уточнить в официальных источниках, прежде чем писать о нём пользователям.
